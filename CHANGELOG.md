# Changelog

## 2.0.0 — 2026-08-31

- Rebuilt the previously empty repository as a Vite-powered vanilla JavaScript game.
- Added the canonical big-number economy, click interaction, saving, offline progress, and responsive game loop.
- Added 20 producers, 140 unique local milestone upgrades, 250 unique achievements, and 16 finite Power Moons.
- Added King Boo's optional top-right slot event with 18 weighted outcomes, reload-safe committed results, timed effects, history, and triple-Boo catastrophe.
- Added the travel-brochure interface, progressive kingdom scenery, Odyssey journey strip, local optimized art, particles, synthesized sound, performance modes, and reduced-motion support.
- Added validated save import/export, Developer Lab controls, content validation, deterministic economy simulation, unit tests, browser tests, and GitHub Pages workflows.
- Fixed late-game pacing, effective-rate display consistency, price curses, overlapping curse safety, hidden-tab progress, malformed save handling, and image fallbacks.
