# Artwork sources

Cappy Clicker is an unofficial, personal, non-commercial fan project. It is not affiliated with, sponsored by, or endorsed by Nintendo. Mario, Cappy, *Super Mario Odyssey*, *Super Mario Sunshine*, and all other referenced Mario games, characters, locations, and artwork belong to Nintendo and their respective rights holders.

The MarioWiki-linked files below are Nintendo/Mario reference material: official artwork, game models and assets, screenshots, or scans as identified on each linked file page. MarioWiki is listed for provenance and its source/fair-use notes; its hosting of a file does not relicense the underlying Nintendo material to this project. Downloading, resizing, converting, or generating a derivative for a personal project does not grant redistribution or commercial-use rights. Replace or remove these assets before using the project in any context that requires licensed redistribution.

Runtime files are downloaded once, resized where useful, and served locally. The game does not hotlink these pages. `scripts/fetch-assets.mjs` resolves each `File:` title through the MarioWiki API before producing the local runtime file.

## Shine and Gloom Shine assets

The official Nintendo Shine reference and the generated runtime pair have separate provenance:

| File or source | Provenance and role |
|---|---|
| [File:SMS_Shine_Sprite_Artwork.png](https://www.mariowiki.com/File:SMS_Shine_Sprite_Artwork.png) | Exact MarioWiki source title for the official *Super Mario Sunshine* Shine Sprite artwork. `scripts/fetch-assets.mjs` can download and convert this to `assets/shines/shine-sprite.webp`, but that fetched file is only a temporary baseline in the current workflow. |
| `scripts/source-assets/shine-pair.png` | OpenAI-generated development sheet made for this fan project. It is kept outside `public/` so the unused 1.6 MB source sheet is not shipped in the production build. It contains a gold Shine-style reference on the left and the authored cracked purple “Gloom Shine” derivative on the right. This sheet is not an official Nintendo asset, but both designs visibly derive from Nintendo's Shine Sprite motif and should not be treated as rights-free commercial artwork. |
| `scripts/split-shine-assets.mjs` | Local post-processing script. It flood-fills the generated checkerboard matte, splits the sheet in half, trims each subject, resizes it onto a transparent 512×512 canvas, and exports alpha-preserving WebP files. |
| `assets/shines/shine-sprite.webp` | Current committed runtime gold Shine, extracted from the left half of the generated pair by `scripts/split-shine-assets.mjs`. It is not the direct MarioWiki download. Running the splitter after `assets:refresh` intentionally overwrites the temporary fetched baseline. |
| `assets/shines/gloom-shine.webp` | Current committed runtime Gloom Shine, extracted from the right half of the generated pair by `scripts/split-shine-assets.mjs`. This purple, cracked corruption is a Cappy Clicker fan-project derivative and is not a canonical or Nintendo-supplied character. |

To reproduce the committed pair, run the normal asset refresh first and then run `node scripts/split-shine-assets.mjs`. Running only `assets:refresh` leaves the official-source gold baseline in `shine-sprite.webp` and does not recreate the generated Gloom output.
