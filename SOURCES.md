# Artwork sources

Cappy Clicker is a personal, non-commercial fan project. Mario, Cappy, *Super Mario Odyssey*, *Super Mario Sunshine*, and related characters and artwork belong to Nintendo and their respective rights holders. Downloading an image for a personal project does not grant redistribution rights. Replace or remove these assets before using the project in a context that requires licensed redistribution.

Runtime files are downloaded once, resized where useful, and served locally. The game does not hotlink these pages. MarioWiki file pages are listed because they preserve provenance and fair-use/source notes for each original.

## King Boo and slot references

The *Sunshine* boss represented here is a distinct Big Boo character that some localized material calls King Boo. Cappy Clicker treats the encounter as a playful crossover and does not claim exact canon fidelity.

| Local file | Source page | Note |
|---|---|---|
| `assets/boo/king-boo.webp` | [Sunshine King Boo model](https://www.mariowiki.com/File:SMSKingBooModel.png) | Event character. |
| `assets/boo/slot-machine.webp` | [Sunshine slot-machine screenshot](https://www.mariowiki.com/File:SMS_Screenshot_Slot_Machine.png) | Visual reference/local fallback asset; the live machine is drawn by HTML/CSS for clarity. |
| `assets/boo/symbol-pineapple.webp` | [Sunshine pineapple](https://www.mariowiki.com/File:SMS_Pineapple_Artwork.png) | Local reel-symbol reference/fallback. |
| `assets/boo/symbol-stu.webp` | [Strollin' Stu](https://www.mariowiki.com/File:SMS_Strollin_Stu_Artwork.png) | Local reel-symbol reference/fallback. |
| `assets/boo/symbol-boo.webp` | [Sleepy Boo model](https://www.mariowiki.com/File:SMS_Asset_Model_Sleepy_Boo.png) | Local reel-symbol reference/fallback. |

The live slot reels use platform emoji so that all eight authored symbols remain legible at the compact top-right event size. These three downloaded symbol images and the screenshot are kept as clearly documented swap-ready references rather than runtime hotlinks.
